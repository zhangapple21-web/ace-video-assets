# ACE video public references

This repository is the public transport surface for explicitly published ACE
video reference media. It contains character/scene stills and selected,
user-authorized dialogue tracks used by provider compatibility tests.

- No credentials, tokens, project archives, logs, or private production files.
- Every directory must contain a manifest with purpose and SHA-256 checksums.
- Raw URLs are intended for provider fetches and may be rotated independently.
- Unlisted audio, video outputs, chat material, and unrelated user files do not
  belong here.

The `references/wenji-episode-006/` directory is the migrated public home for
the former unnamed repository's continuity anchors. Existing consumers should
use this repository instead of `zhangapple21-web/-`.
